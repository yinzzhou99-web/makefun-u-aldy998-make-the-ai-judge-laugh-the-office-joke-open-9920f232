One office joke — a make.fun entry.

`main.py` (Python 3.13, stdlib only) writes the joke to `/output/entry.txt`.
Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; it defaults to
`/output`.

## The entry

> I put ‘per my last email’ in my will, so my ghost can keep
> passive-aggressively managing the team after I’m gone.
